# Bundled font sources

Noto Sans Khmer and Kantumruy Pro from google/fonts, commit 24ddc1f324cac5d9f5aedca126d298f56e3f1640.
Source directories: ofl/notosanskhmer and ofl/kantumruypro.
Both use SIL Open Font License 1.1; the full notices are included beside the fonts.
Subsets preserve Khmer shaping tables, Khmer symbols, Latin and digits.
Rebuild with scripts/subset-fonts.py (fonttools 4.68.0, brotli 1.2.1).
Development downloads only; fonts are served from local bundled files at runtime.
